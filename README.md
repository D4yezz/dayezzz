## 📌 Project Overview

**Dayezzz** is the personal portfolio website of **Dias Adi** (*Frontend & Full-Stack Web Developer*). Designed with a signature *cinematic monochrome* aesthetic, fluid micro-interactions, and a modern user experience (UX), it showcases engineering experience, technical skills, and web development projects.

### 🌐 Live Demo
Explore the live portfolio at: **[https://www.dayezzz.my.id](https://www.dayezzz.my.id)**

---

## ✨ Key Features

- 🎨 **Cinematic Monochrome Design System**: Elegant dark theme with curated typography (*Geist, Lato, Montserrat, Poppins, Inter*).
- 🌀 **Smooth Scroll & Micro-Animations**: Seamless inertia scrolling via **Lenis**, paired with fluid animations built with **Framer Motion** and **GSAP**.
- 🎛️ **Custom Cursor & Interactive Elements**: Tailored cursor feedback and dynamic, responsive UI components.
- 📁 **Interactive Project Showcase**: Dynamic presentation of full-stack and frontend applications with tech stacks, repository links, and live demos.
- 📱 **Fully Responsive Layout**: Optimal visual fidelity across all screen sizes (*Desktop, Tablet, Mobile*).
- ⚡ **SEO & Performance Optimized**: Integrated JSON-LD structured data, OpenGraph metadata, Twitter Cards, and Vercel Analytics.

## 📂 Directory Structure

```text
dayezzz/
├── public/                    # Static assets (project images, favicons, OG images)
├── src/
│   ├── app/                   # Next.js App Router (pages, layout, metadata)
│   │   ├── about/             # About Me page
│   │   ├── contact/           # Contact page
│   │   ├── projects/          # All Projects showcase page
│   │   ├── layout.tsx         # Root layout & providers setup
│   │   └── page.tsx           # Main Landing Page
│   ├── components/
│   │   ├── layout/            # Reusable layout components (Navbar, Cards, Transitions)
│   │   ├── providers/         # Context providers (Lenis, Tooltip)
│   │   ├── ui/                # UI Primitives (Cursor, Buttons, Magnets)
│   │   └── views/             # Page view sections (Home, About, Contact, CTA)
│   ├── hooks/                 # Custom React Hooks (useMediaQuery, useCursor, etc.)
│   ├── lib/                   # Utility functions & configuration
│   ├── store/                 # State management (Zustand)
│   ├── types/                 # TypeScript interfaces & types
│   └── utils/                 # Static data & helpers (projects.ts)
├── package.json
└── tailwind.config.ts
```

## 💻 Getting Started

### Prerequisites
Make sure you have the following installed on your machine:
- **Node.js**: version `18.x` or higher
- **npm** / **pnpm** / **yarn** / **bun**

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/D4yezz/dayezzz.git
   cd dayezzz
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or: pnpm install / yarn install / bun install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` to view the application.
